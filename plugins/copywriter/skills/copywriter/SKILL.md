# Copywriter (copy first, humanizer last)

Two passes, always in this order:
1. **Copy pass:** make it sell, using the notes in `references/`.
2. **Humanizer pass:** make it read like a person wrote it, without changing any fact the copy pass settled.

## Sources (read before writing)

- `references/playbook.md`: always read this first. It holds the three tests, the selling order, the seven levers, the formats and the 10-point check.
- Open the detailed notes only for the format in hand:
  - headlines, subject lines, hooks: `references/headlines.md`
  - clear writing, benefits, the selling sequence, research: `references/clear-writing-and-selling.md`
  - cold letters, ads, flyers, brochures: `references/print-flyers-and-letters.md`
  - landing pages and websites: `references/landing-pages-and-websites.md`
  - email, cold email, follow-up sequences: `references/email.md`
  - social posts, video scripts, online ads, PR, content: `references/social-video-ads-content.md`
  - which lever to pull, and proof with zero customers: `references/persuasion-levers.md`
  - DMs, cold outreach, curiosity bullets, the three tests in depth: `references/lessons-dry-tyson-georgi.md`
- Humanizer rules: `references/humanizer.md`.

## Copy pass

1. **Work out the job.** What it is (hook, email, DM, post, page), who reads it, where it's posted, and the one action wanted. If the user didn't say, pick the likeliest and name it in one line.
2. **Follow the selling order:** their problem in their words, then what it costs them, one promise as a benefit, proof, then one small next step.
3. **Run Harry Dry's three tests on every line.** Can I picture it? Can it be proved true or false? Could a competitor say it? Fix or cut any line that fails.
4. **Use only levers backed by real facts.** Never use fake scarcity, fake proof or fake deadlines.
5. **Keep anything unproven in [brackets]:** amounts, dates, results, reviews and clients the user hasn't given. Never invent a number.
6. **For headlines and hooks,** write 4-5 options using different headline types, score them on the 4 U's, and lead with the best one.
7. **House rules:**
   - Never open a cold message with "I'm [name]" or "My name is". The name goes at the bottom.
   - Plain words a 12-year-old can read.
   - Cold emails under 100 words, DMs under 60.
   - The goal of a cold message is a reply.
   - If the user has their own rules (tone, banned words, length), theirs win.

## Humanizer pass

Run `references/humanizer.md` on the finished copy. Here, the copy pass's output is the "original":
- Keep every fact, number, [bracket], name, link and call to action it contains.
- Add nothing.
- Strip em dashes, curly quotes, AI words, "not X but Y" lines, reflexive triplets, stated morals, padding and chatbot leftovers.
- Keep the user's English variety (British, American, Nigerian and so on).
- Copy needs its hook and its ask, so never cut them as "promo tone". Do cut empty hype words (seamless, game-changer, unlock, elevate).

## Final check

After both passes, run the playbook's 10-point check once more. If the humanizer pass broke a copy rule (for example, it lost the specific number or the one next step), restore it in plain words.

## Output

- Lead with the best version, ready to paste. Put alternatives under it, each with one short line saying why it works.
- List the [brackets] the user must fill in.
- Add 2-3 short rules for using it, only if they help, such as "show real numbers even on zero days".
- No preamble, and no list of changes unless asked.
- Never post or send anything. The user does that.
